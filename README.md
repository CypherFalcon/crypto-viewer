# crypto-viewer
## 📄 Sobre o Projeto

O CriptoViewer é uma aplicação desktop simples, desenvolvida para a visualização de cotações de diversas criptomoedas em tempo real, por meio da API do CoinMarketCap, com possibilidade de armazenamento dos dados em um banco de dados local ou na nuvem (Cloud).

A aplicação conta com uma interface gráfica que facilita sua utilização pelo usuário final, possibilitando o acesso a informações de forma rápida e intuitiva, com poucos cliques.

Este projeto tem como propósito o aprendizado e a prática das ferramentas de programação, frameworks e bibliotecas envolvidas em seu desenvolvimento, deixando registrada minha evolução e desenvolvimento de habilidades ao longo dessa jornada.

---

## >_ Funcionalidades

A aplicação permite que os usuários selecionem o ativo desejado e consultem diversas informações relacionadas à criptomoeda, incluindo:

- Valor mínimo registrado no período selecionado;
- Valor máximo registrado no período selecionado;
- Variação de preço ao longo do período;
- Informações sobre o ativo, como descrição e dados relevantes;
- Alertas de preço, para acompanhar determinados valores;
- Notícias diárias relacionadas ao ativo selecionado.
